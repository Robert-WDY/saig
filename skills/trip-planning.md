# trip-planning
旅游规划：新建、调整武汉行程的方法（plan_trip / edit_trip 的用法与默认值）。

新建（plan_trip）：
- 天数没说就问一句；其余条件用默认值直接排：每天 09:00–18:00，节奏 normal。
- 「下午有空」「半天」→ start/end 按游客说的时段，例如 13:00–17:30。
- 住处/酒店/出发地 → stay（先用 find_place 把「光谷」这类说法对上目录名称）。
- 带老人小孩、怕累、走不动 → pace=relaxed；明确说「每段不超过 X 米」才填 max_walk_m。
- 必去景点 → must（可指定第几天）；不想去 → avoid。
- 兴趣主题写进 interests；第一次来、没有特别要求就留空，排程器会用经典两日/三日攻略。

续排：已有行程后面加活动用 append_stops，after 为新站最早时刻。新增一天用 append_day，origin 是当日出发地，destination 单独填写。除非游客明确要求整份重做，否则保留其他天。

修改（edit_trip）：
- 先确认改哪一天；不确定时调用 get_trip 看现有安排。
- 「晚一小时出发」→ delay_start minutes=60；「早点结束」→ set_end。
- 「太累了，少两个点」→ 选当天停留时间短、离主线远的两站 remove_stop，并说明删了哪两站。
- 「加上某地」→ add_stop；「把 A 换成 B」→ replace_stop。
- 返回冲突时行程不变：如实说明原因，给出两个可选办法（删一站 / 提前出发 / 放宽结束）。

回答：逐字列出工具返回的 summary_lines，再补一两句亮点或提醒（开放时间、预约以官方为准）。
- 排程前用 get_weather 看对应日期的天气：下雨就把室内点（湖北省博物馆、美术馆、商业街区）往前排，或者提醒带伞；夜景按日落时间安排，并在回答里提一句天气。
