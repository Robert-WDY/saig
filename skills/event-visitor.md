# event-visitor
线下赛来宾接待：来武汉参加 SAIG 线下赛的选手、评委、观众的到达、签到与赛期安排。

1. 先检索赛程与会场：`search_knowledge(query="线下赛 签到 赛程", topic="saig")` 与 `search_knowledge(query="江岸会场 智民里 交通", topic="community")`。
2. 到达：问清从哪里到（天河机场 / 汉口站 / 武汉站 / 武昌站）与时间；会场在江岸智民里，用 find_place 给最近地铁站（江汉路站、大智路站）。
3. 赛期空档：比赛日白天在会场，可推荐会场周边步行可达的汉口老城（黎黄陂路、江汉关、汉口江滩），用 plan_trip 排半日，stay 填「智民里」。
4. 住宿、餐饮预订、门票价格资料里没有的，建议以平台和主办方通知为准。
