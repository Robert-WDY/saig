# 武汉接线台 · 武汉数命 SPU 城市 AI 接待员

## 报名表项目简介

第一次来武汉，可以从一句“武汉三镇是哪三镇？”问起，了解两江怎样把城市分成三镇、汉口人爱去哪里过早，也可以跟着江豚 3D 飞览，从古琴台一路看到东湖。想自己逛，就在武汉地图上筛选景点、大学和美食，把想去的地点点进行程，再沿自己的路线逐站飞览。

“武汉接线台”能按出行天数、同行人的偏好和赶车时间编排行程，也能同时给出一日游、两日游并比较。临时说一句“第二天下午四点要到汉口站”，接待员会只重排受影响的那一天，核对转场和到站时间，再更新两份方案的比较。游客还可以接着问，智民里的数命 SPU 社区如何用真实订单带教、什么是超级个体单元，以及参加 SAIG 要准备哪些材料。行程由大模型理解需求、程序校验约束，社区与赛事问答则从资料库检索，并附上出处。
