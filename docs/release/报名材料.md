# 武汉接线台 · 武汉数命 SPU 城市 AI 接待员

## 报名表项目简介

第一次来武汉，可以从一句“武汉三镇是哪三镇？”开始，接着问汉口怎么过早，或请接待员比较一日游和两日游。遇到临时要赶车的情况，可以只改两日游的第二天，让接待员保留其他安排，重新核对到站时间，并在地图上逐站查看路线。接待员也能根据赛事和社区资料介绍智民里的数命 SPU 社区、真实订单带教、超级个体单元和 SAIG 参赛材料，回答附资料出处。网页可静音使用。
